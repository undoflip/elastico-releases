# Elastico releases

Установщики Elastico для Windows и подписанный манифест обновлений.

Каждый выпуск `v<версия>` содержит:

- `Elastico-Setup-<версия>.exe` — установщик;
- `latest.json` — версия, имя файла, размер и SHA-256 установщика;
- `latest.json.sig` — подпись Ed25519 манифеста.

Приложение само проверяет выпуски по HTTPS и ставит установщик только после
сверки подписи, размера и SHA-256.
